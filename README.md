## What I build

**🌐 Web platforms & studios**
End-to-end web products: corporate sites, e-commerce, marketplaces, sales CRMs and admin panels. I run [Ronesin](https://ronesin.com) — a Bursa-based web design & development studio — and [Siyah Labs](https://siyahlabs.com), a digital product studio.

**🏭 Industrial & IoT systems**
Motor test rigs speaking Modbus RTU, MQTT telemetry pipelines (EMQX → Telegraf → InfluxDB → Grafana), QR-based attendance tracking, and remote monitoring for real machines in real facilities.

**⚙️ Ops & automation**
Self-hosted infrastructure on VPS (Coolify, Docker, Traefik), workflow automation with n8n, financial reconciliation tooling, and glue code that removes manual work.
